# A 14-square tiling of the 697 × 611 rectangle

<!-- visual:start -->
<p align="center"><img src="https://raw.githubusercontent.com/jvvk/jvvk/c7403d6bbbc7106e1780d8c34833854afcb0116f/assets/squaring.svg" width="760" alt="minimal-squaring-697x611"></p>

<p align="center"><b>The rectangle needs exactly fourteen squares, not seventeen, so it is not a counterexample to the minimal squaring conjecture.</b></p>

<p align="center"><sub><a href="https://github.com/jvvk/mathematics/tree/main/squared-rectangle-697x611">the paper, with its checks</a> · <a href="https://github.com/jvvk/mathematics">all results</a></sub></p>
<!-- visual:end -->

Square sides: 371, 326, 285, 240, 172, 68, 41, 37, 35, 35, 34, 34, 33, 4 (areas sum to 697 × 611 = 425,867).

![697 × 611 tiled by 14 squares](tiling_697x611.png)

Placements (x, y, side), origin at the bottom-left corner:
(0,0,371) (371,0,326) (371,326,41) (412,326,285) (371,367,4) (375,367,37) (0,371,240) (240,371,68)
(308,371,34) (342,371,33) (342,404,35) (377,404,35) (308,405,34) (240,439,172)

Context: the MathOverflow question [tiling a rectangle with the smallest number of squares](https://mathoverflow.net/q/116382), which asked whether a 17-square tiling of this rectangle is minimal ([answer](https://mathoverflow.net/a/515613)).
